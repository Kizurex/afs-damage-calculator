# AFS Damage Calculator

Damage calculator and rebalance sandbox for Anime Fighting Simulator.

Pick a move, set up a loadout (target, stats, champion, trait, title, accessories,
transformation, stand) and see its damage, hit count, timings, hitbox size and status
effects. **Compare** ranks every move for that loadout, **Combo** chains moves in order,
and the move card lets you try hypothetical values, custom boosts and multiplicative or
additive bonus stacking before they go into the game. **Diff** lists what you changed
and every value change between site updates. The **Guide** tab explains each field.

The site is static: open `index.html` in a browser, or use https://kizurex.github.io/afs-damage-calculator/.
